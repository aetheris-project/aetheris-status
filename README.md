## What it monitors

The status page displays real-time status for all Aetheris platform services, APIs and integrations, organized by category:

### Platform
- Marketing website
- Control panel (admin + client)
- Documentation wiki

### APIs
- Backend API
- Pterodactyl API bridge
- Proxmox VE API bridge
- VirtFusion API bridge

### Integrations
- Stripe payment gateway
- PayPal payment gateway
- Mollie payment gateway
- Cloudflare DNS

### Infrastructure
- GitHub organization
- Vercel deployments
- npm package registry
- WinGet package

## Getting started

```bash
git clone https://github.com/aetheris-project/aetheris-status.git
cd aetheris-status
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

This is a static Next.js site deployed to Vercel. Push to `main` to trigger automatic deployment.

## Tech stack

- Next.js 15 (App Router)
- Tailwind CSS
- TypeScript
